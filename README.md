# 🌾 Agriculture Services Website  
A full-stack agriculture platform designed for farmers to easily access farming products, tools, fertilizers, machinery and services online.  
Developed using **HTML, CSS, JavaScript, PHP, and MySQL**.

---

## 📌 Project Overview  
This web application provides a digital platform for farmers where they can:  
- Browse agricultural products  
- Add items to cart  
- Request farming-related services  
- Make online orders  
- Contact service providers  
- View product details and prices  

The system also includes an **Admin Panel** for managing products, users, and orders.

## 🚀 **How to Run This Project**

### 1️⃣ Install XAMPP  
Download from: https://www.apachefriends.org/

### 2️⃣ Move Project Folder  
Copy the project folder into:

C:/xampp/htdocs/

### 3️⃣ Start Apache & MySQL  
Open **XAMPP Control Panel** → Start both.

### 4️⃣ Create Database  
- Open browser → http://localhost/phpmyadmin  
- Create new database: `agri_db`  
- Import file: `database.sql`

### 5️⃣ Run the Website  
Open in browser:
http://localhost/agriculture_project/
